# Azure Virtual Machine Lifecycle & Disks

Scripts, configurations, and documentation focused on managing Azure virtual machines, disk management, and lifecycle operations.

## Overview
This repository serves as a workspace for practicing and documenting cloud administration tasks, resource management, and automation workflows involving Microsoft Azure virtual machines and storage disks.

## Topics Covered
* Provisioning and configuring Azure Virtual Machines (VMs)
* Managing OS and data disks (creation, attachment, resizing, and snapshots)
* Automating operations and lifecycle tasks
* Network and security rule considerations

## Repository Structure
* `scripts/` - Automation and management scripts
* `docs/` - Notes, architectural diagrams, and step-by-step lab guides
